# Code 128

Линейный код переменной длины для любых символов ASCII. Генераторы `Code128SvgGenerator` и
`Code128PngGenerator` работают как остальные генераторы пакета: `BarcodeType::Code128` плюс формат
из `BarcodeOptions`. Дополнительных опций у типа нет.

## Наборы символов

Code 128 состоит из трёх наборов, и кодировщик переключается между ними сам:

- **C** — пары цифр: два знака в одном символе, поэтому цифровые значения занимают вдвое меньше места;
- **A** — управляющие символы (коды 0-31) и верхний регистр;
- **B** — печатные символы, включая строчные буквы.

Правила выбора: значение целиком из цифр чётной длины кодируется набором C; последовательность от четырёх
цифр внутри значения тоже уходит в C, причём нечётная последовательность выравнивается — одна цифра
остаётся в текущем наборе. Для управляющего символа кодировщик переключается в A, для строчных букв — в B.

Символы вне ASCII (например кириллица) не поддерживаются: используйте DataMatrix или QR.

## Контрольная сумма

Контрольный символ mod 103 обязателен по стандарту, поэтому добавляется всегда и отключить его нельзя.
Сканеры проверяют его сами и в данные не отдают — в отличие от необязательной контрольной суммы Code 39.

## Размер изображения

Каждый символ занимает 11 модулей, стоп-символ — 13. Свободная зона — 10 модулей с каждой стороны,
она входит в `width` результата. Физическая ширина модуля задаётся через `moduleWidth`.

Под штрихами выводится исходное значение; в SVG подпись экранируется.

## Проверка независимым декодером

Проверка запускается отдельно от PHPUnit и использует ZXing-C++ в контейнере. Декодер проверяет
контрольную сумму, поэтому ошибка в её расчёте приведёт к падению этой проверки.

Из корня монорепозитория:

```bash
docker build -t phpsoftbox-barcode-decode:local packages/Barcode/tests/integration

set -o pipefail
docker run --rm \
  -v "$PWD/packages/Barcode:/app:ro" -w /app \
  phpsoftbox-php-cli php tests/integration/code128-cases.php \
  | docker run --rm -i --network none phpsoftbox-barcode-decode:local /tests/code128_decode_test.py
```

Набор случаев — `tests/Code128Cases.php`: текст, цифры чётной и нечётной длины, смесь букв и цифр,
переход из набора C в текст, строчные буквы, управляющий символ, пунктуация, один символ, две цифры
и длинное значение. Для каждого случая проверяются PNG, растеризованный SVG и SVG, прогнанный через
PDF и растрированный при 300 DPI.
