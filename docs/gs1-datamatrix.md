# GS1 DataMatrix (коды маркировки)

Коды маркировки «Честного знака» печатаются символом GS1 DataMatrix: первым кодовым словом идёт FNC1
(значение 232), затем элементы `01`, `21`, `91`, `92`. Без ведущего FNC1 сканер читает те же байты,
но сообщает идентификатор символики `]d1` вместо `]d2`, и приёмная система может отклонить этикетку.

## Использование

```php
$mark = $generator->generate(
    data: $markCode,
    type: BarcodeType::DataMatrix,
    options: new BarcodeOptions(format: BarcodeOutputFormat::Svg, height: 184, margin: 1, gs1: true),
);
```

- `gs1` по умолчанию выключен: без него вывод байт в байт прежний;
- флаг действует только для `BarcodeType::DataMatrix`, остальные типы его игнорируют — как опции Code 39;
- работает и для SVG, и для PNG.

## Данные

На вход подаётся полный код с разделителями GS (0x1D) и **без** символа FNC1 в самих данных: FNC1
добавляет кодировщик. Разделители внутри данных кодируются ASCII-символом 29 (кодовое слово 30).
Спецификация GS1 допускает в этой роли и FNC1, и GS; «Честный знак» и маркетплейсы используют GS,
и сканеры возвращают его как 0x1D.

Содержимое не проверяется: соответствие AI (`01` + 14 цифр GTIN и далее) остаётся на стороне приложения.

## Размер символа

FNC1 занимает одно кодовое слово, поэтому код на границе ёмкости получает следующий размер символа.
Например, 124 цифры — это ровно 62 кодовых слова и символ 32×32; с `gs1: true` тот же код печатается
как 36×36. Это ожидаемо и проверяется тестом `Gs1DataMatrixTest`.

## Проверка независимым декодером

Проверка запускается отдельно от PHPUnit и использует ZXing-C++ в контейнере: он сообщает идентификатор
символики и отдаёт байты без обработки.

Из корня монорепозитория:

```bash
docker build -t phpsoftbox-barcode-decode:local packages/Barcode/tests/integration

set -o pipefail
docker run --rm \
  -v "$PWD/packages/Barcode:/app:ro" -w /app \
  phpsoftbox-php-cli php tests/integration/gs1-datamatrix-cases.php \
  | docker run --rm -i --network none phpsoftbox-barcode-decode:local /tests/gs1_datamatrix_decode_test.py
```

Набор случаев — `tests/Gs1DataMatrixCases.php`: код маркировки с крипто-хвостом 44 и 88 символов,
тот же код без флага (ожидается `]d1`) и код на границе ёмкости. Для каждого случая проверяются PNG
и растеризованный SVG: байты должны совпасть со входом, включая GS, а идентификатор символики —
с ожидаемым.
